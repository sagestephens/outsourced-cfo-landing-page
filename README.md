This landing page was designed with a strong focus on conversion and user flow rather than visual complexity.

My approach was to keep the experience frictionless by:

* using a single clear CTA throughout the page
* structuring the page around user pain points and outcomes
* prioritising mobile responsiveness and readability
* reducing unnecessary navigation distractions
* building trust early using credibility indicators and clear messaging

The layout was intentionally kept lightweight and performance-focused to ensure fast loading times and a smooth mobile experience.

From a UX perspective, the page follows a simple conversion journey:
Problem → Trust → Solution → Process → CTA

The objective was to create a landing page that feels professional, trustworthy, and action-oriented for startup founders and SMEs looking for financial guidance.
